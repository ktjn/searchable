# Searchable 2.0 Baseline Contract Inventory

## Status

**Completed** — 2.0 implementation is done. This document is preserved for historical reference.

All items classified as **remove**, **completed/deleted**, or **move-internal** have been handled. All items classified as **keep** are retained in the 2.0 release. The 2.0 simplification plan has been fully executed.

### 1.1 `@ktjn/searchable-client` (v1.4.1) — `packages/client`

**Completed/deleted.** The package is replaced by `@ktjn/searchable` (packages/searchable). All **keep** exports are available from `@ktjn/searchable`. All **remove** and **completed/deleted** items are gone. All **move-internal** items are no longer publicly exported.

**Completed/deleted.** The package is consolidated into `@ktjn/searchable`. All **keep** types are available from `@ktjn/searchable`. All **remove** items are gone. `canonicalize` is internal.

### 1.3 `@ktjn/searchable-analysis` (v1.4.1) — `packages/analysis`

**Completed/deleted.** The package is consolidated into `@ktjn/searchable`. All **keep** exports are available from `@ktjn/searchable`. All **move-internal** items are no longer publicly exported.

**Completed/deleted.** Moved to repository tooling.

### 1.5 `@ktjn/searchable-relevance` (private)

**Completed/deleted.** Entire package removed in 2.0 (JSON-only shards).
