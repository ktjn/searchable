# `@ktjn/searchable-format`

TypeScript types for Searchable's manifest and shard formats. The browser
client and TypeScript indexer share these definitions so their view of the
JSON-first index format cannot silently drift.

> Published to GitHub Packages from `v*` release tags. Configure
> `@ktjn:registry=https://npm.pkg.github.com` before installing.

See the [Searchable repository](https://github.com/ktjn/searchable),
[documentation](https://ktjn.github.io/searchable/), and
[feature gallery](https://ktjn.github.io/searchable/gallery/).
